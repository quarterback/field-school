## F. Example only: disputed residential address

**Choice:** A Parks application cannot verify the residency of an applicant at a newly subdivided Inboden address. Should the system reject the request, preserve it for review, or grant provisional access?

**Potential agencies:** Parks owns recreation eligibility; city-county Address/GIS owns map correction; a postal operator or private utility may hold different addresses. The government cannot assume that a digital identity solves an address dispute.

**Alternative 1:** hold the request and give the person a case number. **Alternative 2:** issue limited provisional access while GIS investigates. **Alternative 3:** reject pending proof. The class determines the rule, staffing and deadline. The earlier V2 document chose a 48-hour GeoID process; that is **no longer settled**.

**Test:** resident sees understandable status; reviewer sees the unresolved reason; a corrected source record updates the same case; an external partner's refusal has a documented fallback.

## G. Decision control

When a proposal is accepted, copy its adopted wording into the master decision table. If an implementation test contradicts it, log the discrepancy before changing the code or document. Do not silently treat a draft, an agent guess, or a partner's suggestion as a class decision.
